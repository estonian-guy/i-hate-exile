# Security Policy

## Reporting a Security Issue

If you discover a security or privacy issue involving this repository, please report it privately to the repository owner.

Examples include:

- Accidental exposure of private information.
- Unauthorized access to repository-related accounts.
- Malicious links or files added to the repository.
- Other issues that could compromise the security or privacy of contributors or visitors.

## Reporting Guidelines

Please do not publicly disclose sensitive information or exploit a vulnerability to demonstrate it.

Include a description of the issue and any relevant information needed to understand it.

## Response

Reports will be reviewed by the repository owner.

This is a personal project, so response times and ongoing security support are not guaranteed.

## Scope

This policy applies to the I HATE EXILE GitHub repository and its associated content.

**The historical record must remain secure.**
